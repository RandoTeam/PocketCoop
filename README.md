# PocketCoop

Co-op mini-games for Android — play with friends.

Sessions, settings and saved games are stored in a folder that the app creates in
your own Google Drive, so progress follows you between devices without an account
on our side.

## Links

- Website: https://randoteam.github.io/PocketCoop/
- Privacy Policy: https://randoteam.github.io/PocketCoop/privacy.html

## Data

The app requests the `drive.file` scope and can access only files and folders it
creates itself. No analytics, no advertising, no tracking.

See the [Privacy Policy](https://randoteam.github.io/PocketCoop/privacy.html) for
details.
